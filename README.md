# Sweet proteins designed with increased thermostability
Veronica Ramos-Viana<sup>1</sup>, Teemu K. E. Rönkkö<sup>2</sup>, Gonzalo Nahuel Bidart<sup>1</sup>, Robby Divine<sup>3</sup>, Ditte Hededam Welner<sup>1</sup>, Alexander S. Hauser<sup>2</sup>, David Baker<sup>3</sup>, Leonie J. Jahn*<sup>1</sup>, Morten O. A. Sommer*<sup>1</sup>

<sup>2</sup>Department of Drug Design and Pharmacology, University of Copenhagen, Universitetsparken 2, 2100 Copenhagen Ø, Denmark

<sup>3</sup>Department of Biochemistry, University of Washington, Seattle, WA 98195, USA. Institute for Protein Design, University of Washington, Seattle, WA 98195, USA

This repository contains the computational work done for this publication. The repository is organised as follows:
1. [*0_variant_design_scripts*](./0_variant_design_scripts/) contains the code for Rosetta design approach. This work was done by Robby Divine.
2. [*1_variant_data*](./1_variant_data/) contains the experimental data on designed variants, conducted by Veronica Ramos-Viana.
3. [*2_correlation_analyses*](./2_correlation_analyses/) directory contains the analyses done on the correlation between computational descriptors of proteins with experimentally measured values of protein yield and thermostability. This work done was by Teemu K. E. Rönkkö.
4. [*3_structural_analyses*](./3_structural_analyses/) contains the structural predictions produced by AFsample and AF2 to analyse and visualize the produced sweet protein variants. This work was done by Teemu K. E. Rönkkö.
